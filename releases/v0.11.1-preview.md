# S56K Editor 0.11.1 Preview

**Released 26 October 2026 · Windows x64**

[Download and checksum](README.md) · [Manual](../docs/USER_GUIDE.md) · [Release history](../CHANGELOG.md)

The first public preview brings desktop control and library management to the AKAI S5000 and S6000. Browse computer and sampler files, send WAV samples, AKP programs and AKM multis with their dependencies, or select instruments from supported classic Akai disk images.

The Sampler page follows the instrument automatically. USB driver assistance, LCD capture and local troubleshooting logs live in **Tools**. This build removes the main-page USB Driver Setup button.

## Requirements

- Windows x64; Windows 11 is the current test target.
- An AKAI S5000 or S6000 with an **IB-S56USB card**, powered on and connected by USB.
- Microsoft's WinUSB driver assigned to the Akai USB device.
- Close ak.Sys, the standalone Firmware Updater and other tools using the sampler before connecting.

The Editor does not require a firmware update. Expanded Edition is optional and distributed separately.

## What was checked

The exact public executable was built, stripped of debugging information and checked through the Windows GUI under Wine. Tools-only driver access, missing-device behaviour, screenshots and clean shutdown were exercised. Package contents and checksums were independently checked.

Earlier Editor builds have been used on real samplers during development. Those reports do not establish every image format, hardware configuration or new driver-setup route. **Actual Windows UAC and driver reassignment through the new assistant remain to be verified.**

## Current boundaries

- The release is a preview. Begin with a small transfer and keep copies of your original files.
- The screen view displays the sampler's native LCD; it is not a separate high-resolution parameter editor or sampler emulator.
- Old disk images are converted only where supported; incompatible parameters, conflicting sounds, missing dependencies or malformed content can block preparation. See [formats](../docs/FORMATS.md).
- Transfers to RAM are temporary. Save sounds and their samples to disk before powering off.
- Cancelling a batch requests a stop after the current file; completed files remain at the destination.
- This app does not flash firmware and contains no firmware BIN or bundled updater.
